## 1. 系统概述

### 1.1 业务背景

本系统面向高校教师，基于在线课程成绩历史数据构建机器学习预测模型。教师输入学生的各项指标（出勤率、作业分、期中成绩、课堂参与度等），系统实时输出期末成绩预测值和对应等级，辅助教学干预决策。

### 1.2 功能边界

| 模块 | 核心职责 | 不在范围内 |
|------|---------|-----------|
| 个体预测 | 输入特征值，返回预测分数与等级 | 批量导入学生名单 |
| 总体分析 | 特征重要性排序、相关性热力图 | 自定义指标对比分析 |
| 模型可视化 | 决策树结构图，展示分支规则 | 在线调整超参 |
| 数据管理 | 离线清洗、特征工程、模型持久化 | 在线数据标注 |

### 1.3 非功能需求

| 类别 | 指标 |
|------|------|
| 可用性 | 单次预测 P99 延迟 < 200ms |
| 可维护性 | 模型可通过重跑 `main.py` 热替换，无需重启 Java 服务 |
| 兼容性 | 前端支持 Chrome/Firefox/Edge 最新两个大版本 |
| 部署 | 单机部署，支持一键启动脚本 |

## 4. 数据流设计

### 4.1 训练数据流

```
Score_dataset.xlsx
       │
       ▼
  Data.data_show()
  ├── 读取 Excel
  ├── 缺失值填充 (数值→均值, 文本→众数)
  ├── 范围过滤 (range_limit)
  └── 导出 result.json
       │
       ▼
  Data.feature_choose()
  ├── 只保留数值型列
  ├── Pearson 相关系数 (vs 目标列)
  ├── 阈值过滤 (|r| > 0.1)
  └── 返回 selected_features + target
       │
       ▼
  main.py (防泄漏)
  ├── 剔除共线的子项特征
  ├── 连续值 → 分类标签 (bins: <60, 60-79, 80-89, ≥90)
  ├── train_test_split (80/20, random_state=42)
       │
       ▼
  Algorithm.fit()
  ├── LinearRegression ← y_train_reg
  └── DecisionTreeClassifier(max_depth=5) ← y_train_clf
       │
       ▼
  joblib.dump()
  ├── lr_model.pkl
  ├── clf_model.pkl
  └── model_metadata.json  (feature_names, target_col, class_labels)
```

### 4.2 在线推理数据流

```
User Input (特征滑块值)
       │
       ▼
  Vue PredictView
  ├── GET /api/prediction/features  → 动态生成滑块
  └── POST /api/prediction/predict  → { features: [v1, v2, ...] }
       │
       ▼
  Java PredictionController
  ├── @Valid 校验 (非空, 数组非空)
  └── PredictionService.predict()
       │
       ▼
  HTTP POST → Python /api/predict
  ├── lr_model.predict()   → predicted_score (float)
  ├── clf_model.predict()  → predicted_label (str)
  └── return { code, data: { predicted_score, predicted_label } }
       │
       ▼
  Java → 透传响应 → Vue 渲染结果
```

### 4.3 分析与可视化数据流

```
Vue AnalysisView
  └── GET /api/prediction/analysis
        │
        ▼
      Java → GET Python /api/analysis
        ├── clf_model.feature_importances_  → 柱状图数据
        ├── result.json → 相关性矩阵计算    → 热力图数据
        └── return { code, data: { feature_importance, correlation_matrix } }

Vue TreeView
  └── GET /api/prediction/tree
        │
        ▼
      Java → GET Python /api/tree
        ├── 递归遍历 clf_model.tree_
        ├── 构造 ECharts Tree 格式 { name, children: [...] }
        └── return { code, data: <Tree JSON> }
```

## 5. 模块详细设计

### 5.1 Python 模型层

#### 5.1.1 Data 类

| 属性 | 类型 | 说明 |
|------|------|------|
| `input_path` | `str` | 原始 Excel 数据集路径 |
| `output_path` | `str` | 清洗结果 JSON 输出路径 |

| 方法 | 入参 | 返回值 | 职责 |
|------|------|--------|------|
| `data_show(range_limit, feature_limit=[])` | `range_limit: dict`, `feature_limit: list` | `pd.DataFrame` | 读取 → 缺失值填充 → 范围过滤 → 独热编码 → 导出 JSON |
| `feature_choose(df, target_col, threshold=0.1)` | `df: DataFrame`, `target_col: str`, `threshold: float` | `pd.DataFrame` | Pearson 相关性筛选，保留 |r| > threshold 的特征 |

**缺失值填充策略**:
- 数值型列 → 列均值填充
- 文本型列 → 列众数填充

**独热编码触发条件**: `feature_limit` 参数非空时才执行。当前训练流程在 `main.py` 中将 `线下_互动` 数值列分箱为"参与度等级"（低/中/高）类别特征，通过 `pd.get_dummies()` 执行独热编码，生成 2 个二值列（中参与度、高参与度）。

#### 5.1.2 Algorithm 类

| 属性 | 类型 | 说明 |
|------|------|------|
| `clf` | `DecisionTreeClassifier` | max_depth=5, random_state=42 |
| `lr` | `LinearRegression` | 默认参数 |
| `feature_names` | `list[str]` | 训练时 X 的列名 |

| 方法 | 职责 |
|------|------|
| `fit(X_train, y_train_reg, y_train_clf)` | 双模型联合训练 |
| `predict(X_test)` | 返回 `{regression_predictions, classification_predictions}` |
| `LinearRegression_assessment(X_test, y_test_reg)` | 输出 R² / MAE / RMSE / 特征权重 |
| `tree_assessment(X_test, y_test_clf)` | 输出 Accuracy / Precision / Recall / Confusion Matrix |

**超参选择依据**:
- `max_depth=5`: 数据集经特征筛选后约 5-8 个特征，深度 5 可确保树不退化为一两层的弱分类器，同时避免过拟合
- `random_state=42`: 保证实验可复现

#### 5.1.3 api.py — 推理服务

| 端点 | 方法 | 请求体 | 响应体 | 依赖 |
|------|------|--------|--------|------|
| `/api/features` | GET | — | `{feature_names, class_labels}` | model_metadata.json |
| `/api/predict` | POST | `{features: [float, ...]}` | `{predicted_score, predicted_label}` | lr_model.pkl + clf_model.pkl |
| `/api/analysis` | GET | — | `{feature_importance, correlation_matrix}` | clf_model + result.json |
| `/api/tree` | GET | — | `{name, children: [...]}` (ECharts Tree 格式) | clf_model.tree_ |

**特征预处理**: 前端传入的原始 5 个数值特征在 `_build_features()` 中自动扩展为模型期望的完整特征向量：根据 `线下_互动` 值自动推导参与度等级，追加 2 列独热编码特征，再送入模型推理。对外接口仍保持 5 个特征不变。

**启动前置条件**: `main.py` 至少成功运行一次，生成 `saved_models/` 目录和 `data_show/result.json`。

#### 5.1.4 main.py — 离线训练入口

执行顺序:
1. `Data.data_show(range_limit)` — 数据清洗（缺失值填充 + 范围过滤）
2. 独热编码实践 — 将 `线下_互动` 分箱为"参与度等级"类别，`pd.get_dummies()` 生成独热编码列
3. `Data.feature_choose(df, target_col)` — Pearson 相关性特征选择
4. 剔除共线特征（防数据泄漏：线上总成绩 = 平时 + 期中 + 期末）
5. `pd.cut()` — 连续值离散化为 4 级分类标签（不及格/中/良/优）
6. `train_test_split(80/20)` — 划分训练/测试集
7. `Algorithm.fit()` — 双模型联合训练
8. `Algorithm.LinearRegression_assessment()` — 回归评估（R²/MAE/RMSE/权重）
9. `Algorithm.tree_assessment()` — 分类评估（Accuracy/Precision/Recall/混淆矩阵）
10. `joblib.dump()` — 持久化模型 + 元数据

### 5.2 Java 中间层

#### 5.2.1 Controller 层

`PredictionController` — 映射 `/api/prediction/*`

#### 5.2.2 Service 层

`PredictionService` — 核心职责:

1. 接收前端 DTO，转换为 Python API 期望的 `{features: [...]}` 格式
2. 通过 `RestTemplate` 向 Python FastAPI 发 HTTP 请求
3. 异常时抛出业务异常，不暴露内部错误栈

```java
// 核心调用链路
predict(PredictionRequest) → RestTemplate.postForObject(pythonApiUrl + "/api/predict", ...) → Map<String, Object>
getAnalysis()              → RestTemplate.getForObject(pythonApiUrl + "/api/analysis", ...)
getTree()                  → RestTemplate.getForObject(pythonApiUrl + "/api/tree", ...)
getFeatures()              → RestTemplate.getForObject(pythonApiUrl + "/api/features", ...)
```

#### 5.2.3 DTO 层

`PredictionRequest`: `{ features: List<Double> }` — 与 Python API 的 `PredictRequest` 结构一致，透传策略。

### 8.2 个体预测页交互

1. `onMounted` → 调用 `/api/prediction/features` 获取特征名列表
2. 根据特征名动态渲染 `input[type=range]` 滑块（0-100，步长 1）
3. 点击"开始预测" → 收集所有滑块值 → POST `/api/prediction/predict`
4. 响应成功 → 渲染结果卡片：左侧圆形分数（颜色按等级变化），右侧等级标签 + 分数详情
5. 加载中 → 显示 Spinner 动画
6. 加载失败 → 显示错误信息 + 重试按钮

### 8.3 总体分析页交互

1. `onMounted` → 调用 `/api/prediction/analysis`
2. 渲染两个 ECharts 实例：
   - 柱状图：特征重要性，x 轴为特征名，y 轴为重要性值

3. `window.resize` → echarts.resize() 自适应

### 8.4 模型可视化页交互

1. `onMounted` → 调用 `/api/prediction/tree`
2. ECharts Tree 图：从左到右展开，圆形节点为分支条件，矩形节点为叶子类别

## 11. 安全与容错

### 11.1 安全措施

| 层级 | 措施 |
|------|------|
| 网络 | Python API 仅绑定 127.0.0.1，不接受外部直连 |
| 输入校验 | Java `@Valid` + `@NotEmpty`，Python `len(features) == len(FEATURE_NAMES)` |
| 数据库密码 | 通过 `${DB_PASSWORD}` 环境变量注入，不硬编码 |
| CORS | Spring Boot `@CrossOrigin` 限制来源（开发阶段 `*`，生产应替换） |
| 错误信息 | 对外返回到用户层次，不暴露内部异常栈 |

### 11.2 容错策略

| 故障场景 | 处理方式 |
|---------|---------|
| Python API 不可达 | Java 捕获 `RestClientException`，返回 "预测服务暂时不可用" |
| 模型文件缺失 | FastAPI 启动时 `try/except`，请求时返回 500 |
| 特征数量不匹配 | FastAPI 返回 400，明确告知期望 vs 实际 |
| MySQL 不可达 | JPA 自动重连，不阻断预测链路（预测不依赖 DB） |
| ECharts 渲染失败 | 组件不崩溃，显示空状态提示 |
