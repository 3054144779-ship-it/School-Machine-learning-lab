# 学生成绩预测系统设计文档

## 类

### Data 类

数据层，负责数据读取、清洗与特征工程。

数据源选用：公开的线上课程成绩数据集（`Score_dataset.xlsx`）。

数据清洗：包含缺失值识别与填充（数值型用均值、字符串型用众数）、按合理范围过滤异常值、类别型特征的独热编码（$One-Hot Encoding$）。

特征选择：计算各数值型特征与目标变量的 $Pearson$ 相关系数，按阈值筛掉弱相关特征。

#### 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `self.input_path` | `str` | 原始数据集所在路径 |
| `self.output_path` | `str` | 清洗结果 JSON 输出路径 |

#### 方法

`data_show(self, range_limit, feature_limit=[])`

清洗数据：读取 Excel → 缺失值填充 → 按范围过滤异常值 → 独热编码 → 导出 JSON。

| 参数 | 类型 | 说明 |
|------|------|------|
| `range_limit` | `dict` | 各列的有效范围，格式 `{"列名": [下限, 上限]}` |
| `feature_limit` | `list` | 需要独热编码的类别特征列名列表 |

**返回值**：清洗后的 `pd.DataFrame`。

---

`feature_choose(self, df, target_col, threshold=0.1)`

特征选择：只保留数值型列 → 计算 Pearson 相关系数 → 取绝对值 → 筛掉低于阈值且非目标列的特征。

| 参数 | 类型 | 说明 |
|------|------|------|
| `df` | `pd.DataFrame` | 清洗后的数据 |
| `target_col` | `str` | 目标变量列名 |
| `threshold` | `float` | 相关系数阈值（绝对值），默认 0.1 |

**返回值**：`pd.DataFrame` — 保留下来的特征列 + 目标列。

---

### Algorithm 类

算法层，封装双模型（多元线性回归 + 分类决策树）的训练、预测与评估。

#### 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `self.clf` | `DecisionTreeClassifier` | 分类决策树，`max_depth=5`，`random_state=42`，防过拟合 |
| `self.lr` | `LinearRegression` | 多元线性回归模型 |
| `self.feature_names` | `list[str]` | 训练时传入的特征列名，用于输出权重分析 |

#### 方法

`fit(self, X_train, y_train_reg, y_train_clf)`

分别用连续值目标训练线性回归、用分类标签训练决策树。自动记录特征列名。

| 参数 | 类型 | 说明 |
|------|------|------|
| `X_train` | `pd.DataFrame` | 训练集特征矩阵 |
| `y_train_reg` | `pd.Series` | 连续分数目标（供线性回归） |
| `y_train_clf` | `pd.Series` | 分类标签（供决策树，如 优/良/中/不及格） |

---

`predict(self, X_test)`

对测试集进行双模型预测。

**返回值**：`dict` — `{"regression_predictions": [...], "classification_predictions": [...]}`

---

`LinearRegression_assessment(self, X_test, y_test_reg)`

模型 A 评估：输出 $R^2$（决定系数）、MAE（平均绝对误差）、RMSE（均方根误差），并逐特征输出权重系数及正/负相关性。

**返回值**：`(r2, mae, rmse)`

---

`tree_assessment(self, X_test, y_test_clf)`

模型 B 评估：输出准确率（Accuracy）与混淆矩阵（Confusion Matrix）。

**返回值**：`(accuracy, cm)`

---

### Interact 类

交互层，预留 Web 可视化接口。

目标功能：
- 个体预测：支持教师通过滑块、下拉框输入学生特征，实时预测期末成绩。

## 算法

### 双模型设计

**模型 A — 多元线性回归（`LinearRegression`）**

以连续值（具体分数）为目标进行拟合，输出各特征的权重系数（Weights），分析正/负相关性。
评估指标：$R^2$、MAE、RMSE。

**模型 B — 分类决策树（`DecisionTreeClassifier`）**

以成绩等级（优/良/中/不及格）为分类目标。设置 `max_depth=5` 限制树深度，防止过拟合。
评估指标：准确率（Accuracy）、混淆矩阵（Confusion Matrix）。

### 数据预处理流程（`main.py`）

1. **数据清洗**：定义各列有效范围（如线上_平时成绩 [0,40]、线上总成绩 [0,100]），调用 `Data.data_show()`。
2. **特征选择**：以"线上总成绩"为目标变量，调用 `Data.feature_choose()` 筛出相关特征。
3. **防数据泄漏**：剔除与目标变量完全共线的子项特征（线上_平时成绩、线上_期中测试、线上_期末考试），因为三者之和即线上总成绩。
4. **分类标签生成**：将连续分数按区间映射为四类 —
   - `<60`：不及格
   - `60-79`：中
   - `80-89`：良
   - `≥90`：优
5. **数据集划分**：按 80% 训练集、20% 测试集切分，`random_state=42` 保证可复现。
6. **模型训练与评估**：调用 `Algorithm.fit()` 训练，随后分别执行 `LinearRegression_assessment()` 和 `tree_assessment()`。
